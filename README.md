# Contoso Web App

A modern internal web application for the Contoso organization.

## Getting Started

```bash
npm install
npm run dev
```

## Architecture

- `src/` — Application source code
- `src/index.js` — Express server entry point
- `src/routes/` — API route handlers

## Contributing

Please run `agentrc readiness` before submitting PRs to ensure code quality standards.
